# Analyse des élections présidentielles françaises

Projet réalisé dans le cadre du projet fil rouge IA & Data.

## Objectif

Analyser les élections présidentielles françaises de 1995 à 2022 afin d’identifier les tendances électorales et explorer des scénarios possibles pour l’élection présidentielle de 2027.

## Données utilisées

Résultats électoraux :
- 1995
- 2002
- 2007
- 2012
- 2017
- 2022

Sources :
- Ministère de l'intérieur
- data.gouv.fr

Données démographiques :
- INSEE
